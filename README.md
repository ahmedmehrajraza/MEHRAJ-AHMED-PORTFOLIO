# ARKITEKT - Architecture Portfolio

A minimal, premium architectural portfolio website.

## Features
- **Premium Design Aesthetics**: Dark mode default with a clean, grid-based layout.
- **Responsive**: Fully responsive on mobile, tablet, and desktop.
- **Interactions**: Smooth scrolling, custom cursor, and micro-animations.
- **Theme Support**: Light/Dark mode toggle.

## How to Run
Simply open `index.html` in your web browser.

Alternatively, you can run a local server:
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000`

## Structure
- `index.html`: Main structure.
- `style.css`: All styling and variables.
- `script.js`: Logic for animations and interactions.
